# Round Robin Process Scheduling Simulation

## Overview

This project was created practing operating system concepts.This simulates the Round Robin scheduling algorithm used in operating systems. The program creates processes, places them in a ready queue, executes them using time slices, and tracks process completion.

## Installation Instructions

1. Download or clone this repository.
2. Open the files in Code::Blocks or another C IDE.
3. Compile the program files.
4. Run RR.c.

## Usage Instructions

1. Run the program.
2. Enter a simulation time.
3. The program generates processes and simulates Round Robin scheduling.
4. The console displays process arrivals, execution, queue activity, and completion information.

Example output:

```text
NEW PROCESS: PROC1 | ID: 1 | Time: 7

RUNNING: PROC1 | ID: 1 | Remaining: 7

NOT FINISHED: PROC1 | Remaining: 4

COMPLETE: PROC1
```
